## 🔍 Как работает JSONP

### Обычный fetch (блокируется CORS):
```javascript
fetch('https://script.google.com/...', {
  method: 'POST',
  body: JSON.stringify(data)
})
```

### JSONP (обходит CORS):
```javascript
// Создается <script> тег с данными в URL
<script src="https://script.google.com/...?name=Test&callback=jsonpCallback_123"></script>

// Google Apps Script возвращает:
jsonpCallback_123({"success": true, "message": "Заявка отправлена"})
```

## 🎯 Преимущества JSONP

- ✅ **Обходит CORS ограничения**
- ✅ **Работает с локального сервера**
- ✅ **Работает с продакшена**
- ✅ **Простая реализация**
- ✅ **Надежная доставка данных**

## 🐛 Возможные проблемы

### 1. Google Apps Script не обновлен
**Симптом**: Ошибка "callback is not defined"
**Решение**: Убедитесь, что код в Google Apps Script обновлен

### 2. Неправильный URL
**Симптом**: Ошибка загрузки скрипта
**Решение**: Проверьте URL в `googleSheets.ts`

### 3. Таймаут
**Симптом**: "Таймаут запроса"
**Решение**: Увеличьте `TIMEOUT` в `googleSheets.ts`
