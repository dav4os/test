## Обзор изменений

Проект был обновлен для использования WebP формата изображений, что обеспечивает:
- Уменьшение размера файлов на 25-35%
- Ускорение загрузки страниц
- Лучшую производительность сайта

## Как использовать

### Автоматическая оптимизация

Для автоматического использования WebP изображений используйте функции из `imageUtils.ts`:

```typescript
import { getOptimalImagePath } from '../utils/imageUtils';

const imagePath = getOptimalImagePath('/path/to/image.jpg');
// Вернет '/path/to/image.webp' если WebP доступен, иначе '/path/to/image.jpg'
```

### Для статей блога

Используйте функции оптимизации:

```typescript
import { getOptimizedBlogArticles, getOptimizedBlogArticle } from '../data/blogArticles';

// Получить все статьи с оптимизированными изображениями
const optimizedArticles = getOptimizedBlogArticles();

// Получить одну статью с оптимизированным изображением
const optimizedArticle = getOptimizedBlogArticle(article);
```

### Компонент OptimizedImage

Для автоматического fallback используйте компонент `OptimizedImage`:

```typescript
import OptimizedImage from './OptimizedImage';

<OptimizedImage
  src="/path/to/image.jpg"
  alt="Описание изображения"
  className="w-full h-64 object-cover"
/>
```

## Преимущества

1. **Уменьшение размера файлов**: WebP файлы на 25-35% меньше JPG
2. **Ускорение загрузки**: Быстрее загружаются страницы
3. **Лучшая производительность**: Меньше трафика и быстрее отображение
4. **Автоматический fallback**: Если WebP не поддерживается, используется JPG
5. **Обратная совместимость**: Старые браузеры получают JPG версии

## Поддержка браузеров

WebP поддерживается всеми современными браузерами:
- Chrome 23+
- Firefox 65+
- Safari 14+
- Edge 18+

Для старых браузеров автоматически используется JPG fallback.

## Рекомендации

1. При добавлении новых изображений создавайте WebP версии
2. Используйте функции из `imageUtils.ts` для автоматической оптимизации
3. Тестируйте на разных браузерах для проверки fallback
4. Мониторьте производительность загрузки изображений
